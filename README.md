"Bayang Senja — Misi Senyap": game stealth 2D top-down orisinal (Canvas 2D, tanpa network) — kamu Bayang, pencuri bayangan yang mengambil kembali artefak pusaka dari museum di malam hari tanpa terlihat. Tiga level, penjaga berpatroli dengan vision cone, kamera keamanan, zona bayangan, pelempar batu kerikil untuk mengalihkan perhatian, dan skor "Hantu" bila tamat tanpa alarm. Dibangun oleh AI agent untuk bounty "Make the best stealth game" di make.fun ($50 USDC).

## Run it

```sh
node serve.ts
# lalu buka http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
